# Content rules

## Note card format

Every topic card carries, in this order: **5-second idea**, **Remember**, **Tiny example**, **GATE angle**,
**Variations**, **Trap alert**, **Quick check + answer**, plus sources, priority and prerequisites.
A card that needs more than this gets an extra page, not a longer card.

## Writing

- Simple English, beginner first. Explain a technical word the first time it appears.
- Short bullets over paragraphs; a tiny example over an abstract description.
- State the assumption that makes a formula valid (empty boxes allowed? order significant? boxes labelled?).
- Never trade correctness for brevity.

## Question labels

| Label | Meaning |
| --- | --- |
| `VERIFIED PYQ` | a real previous-year question, answer checked |
| `ORIGINAL PYQ-STYLE QUESTION` | new question written in exam style |
| `CONCEPTUAL PRACTICE QUESTION` | checks understanding, not exam format |
| `PREDICTED VARIATION` | a plausible twist on a verified pattern |

Only the first may be described as a previous-year question.

## Priority

- **P1** - foundational or repeatedly useful; everything else depends on it.
- **P2** - important application or a distinct question pattern.
- **P3** - supplementary, or enumerate-only material.

Priority is justified from syllabus position, dependencies and verified PYQ evidence - never from an invented
probability of appearing in the exam.
