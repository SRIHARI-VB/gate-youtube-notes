## Concepts extracted

- In propositional logic every variable is a propositional (Boolean) variable.
- The domain of every propositional variable is the set {true, false}; the variable takes one of those two values.
- That domain is a set of values, also called the universe.
- Conjunction binds tighter than implication, so the conjunction inside an implication is evaluated first.
- An implication whose antecedent is false is true, whatever the consequent is.
- In first-order logic a variable can refer to any domain, and different variables can have different domains.
- Domains used as illustrations: the natural numbers, the integers, {true, false}, and a two-element set.
- First-order variables are illustrated with letters such as x, y and z.
