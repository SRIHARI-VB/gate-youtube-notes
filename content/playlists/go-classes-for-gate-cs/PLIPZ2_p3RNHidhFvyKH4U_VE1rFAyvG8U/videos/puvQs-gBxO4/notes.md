## Concepts extracted

- First order logic is also called predicate logic, and also quantification logic.
- The lecture covers both directions of translation: English to first-order logic and first-order logic to English.
- The running predicates are R(x) meaning 'x is a rabbit' and C(x) meaning 'x is cute'.
- 'Every rabbit is cute' means: for every element, if it is a rabbit then it is cute - for all x, R(x) implies C(x).
- The domain contains other animals too, not only rabbits, which is why the universal statement uses an implication.
- Template 1, 'all A's are B's', is written: for all x, if x is A then x is B.
- 'Some rabbit is cute' means there is at least one element that is a rabbit and is cute.
- 'Some' means at least one, so the two properties are joined with 'and' inside the existential quantifier.
- Template 2, 'some A's are B's', is written: there exists x with A(x) and B(x).
- The instructor calls Template 1 a standard template that will be used many times.

## Worked examples in the readable part

- 'Every rabbit is cute' becomes: for all x, R(x) implies C(x).
- 'Some rabbit is cute' becomes: there exists x with R(x) and C(x).

## What the instructor warns about

- The universal quantifier ranges over the whole domain, so the 'is a rabbit' condition has to be an implication.
- The existential needs both properties true of the same element, so they are joined with 'and'.
