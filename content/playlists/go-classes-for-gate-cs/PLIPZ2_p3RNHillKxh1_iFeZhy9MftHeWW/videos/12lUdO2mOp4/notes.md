## Concepts extracted

- To know the truth value of a compound proposition you need the truth value of each variable in it - nothing else.
- An interpretation is an assignment of a truth value to every propositional variable of the sentence; formally, the assignment of Boolean values to the variables.
- Each row of a truth table is one interpretation.
- A sentence with n variables has 2^n interpretations: 4 for two variables, 8 for three.
- A model of a sentence is an interpretation under which the sentence is true.
