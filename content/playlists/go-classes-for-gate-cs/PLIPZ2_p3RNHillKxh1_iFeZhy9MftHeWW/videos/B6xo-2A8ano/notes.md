## Concepts extracted

- First step on any argument question: translate the English argument into argument form, giving every premise and the conclusion a variable.
- Worked opening question: 'it rains' = R, 'the cricket match will not be played' = not P; premises R -> not P and P, conclusion not R.
- Validity test taught here: make the conclusion false, then try to make every premise true. If that is impossible, the argument is valid; if it is possible, the argument is invalid.
- In the worked question, making the conclusion false forces R true, and then premise R -> not P with P true cannot both hold, so the argument is valid (this is modus tollens).
- Premises are also called hypotheses or antecedents.
