Inclusion-Exclusion and Derangements

Objective. Watch the alternating add/subtract pattern repair double counting, then use it to count derangements.
1.00x

Static explanation

For two finite sets, |A| + |B| counts every element of the overlap twice. Subtracting the overlap once gives each element exactly one count: |A u B| = |A| + |B| - |A n B|. With |A| = 6, |B| = 5 and |A n B| = 2 the union is 9.

For three sets the signs alternate: add the three singles, subtract the three pairwise overlaps, add the triple overlap back. An element in all three sets was added three times and subtracted three times, so without the final term it would be missing.

A derangement is a permutation with no fixed point, and it is counted by inclusion-exclusion: start from n!, subtract the permutations fixing each element, add back those fixing two elements, and so on. That gives !n = n! (1 - 1/1! + 1/2! - ... + (-1)^n/n!).

For three letters: 3! = 6 permutations, and only BCA and CAB have no fixed point, so !3 = 2. The values continue !4 = 9, !5 = 44, !6 = 265.

Common misconception

You cannot divide a derangement count by the factorial of repeated letters. For the word LILAC the shortcut !5 / 2! gives 22, but the correct answer is 12, because each copy of L has its own forbidden original position, so the two copies are not interchangeable in the way the division assumes. Do a case analysis instead (GATE CS 2020 Q.42).

Quick check

How many derangements does a 4-element set have?

Answer

9, from !4 = 4! (1 - 1 + 1/2 - 1/6 + 1/24) = 24 - 24 + 12 - 4 + 1 = 9, or from the recurrence !n = (n-1)(!(n-1) + !(n-2)) with !2 = 1, !3 = 2.
