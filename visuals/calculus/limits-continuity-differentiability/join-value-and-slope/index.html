Matching Value and Slope at a Join

Objective. See why a piecewise function needs two equations at its join - one for the values and one for the slopes - and why the value equation can never be skipped.
1.00x

Static explanation

Let f(x) = ax + b for x < 1 and f(x) = x^3 + x^2 + 1 for x >= 1. Everything happens at x = 1, because that is the only point where the formula can change.

Continuity at 1 asks for one equation: the left-hand value a(1) + b must equal the right-hand value 1 + 1 + 1 = 3. So a + b = 3. With a = 0 and b = 0 the left-hand value is 0 while the right-hand value is 3, a jump of 3, and the function is not even continuous. With a = 1 and b = 2 the values agree at 3 and the function is continuous.

Differentiability at 1 asks for a second equation: the left-hand slope must equal the right-hand slope. The left piece is a line of slope a. The right piece has derivative 3x^2 + 2x, which at x = 1 is 3 + 2 = 5. So a = 5. With a = 1 and b = 2 the slopes are 1 and 5 - the pieces meet but with a corner, and the derivative does not exist at x = 1.

With a = 5 the value equation gives b = 3 - 5 = -2. The line arrives at (1, 3) with slope 5 and the cubic leaves with slope 5, so the join is smooth and f is differentiable everywhere. That is the answer to GATE CSE 2025 Set 1 Q.21, which asks for b under the hypothesis that f is differentiable everywhere.

Solve the equations in this order, always: continuity first, because a function that is not continuous at the join cannot be differentiable there, and the slope equation is then applied to a function whose values already agree.

Common misconception

Reading the word "continuous" in a question as though it licensed the slope equation. Continuity gives only a + b = 3, a whole family of pairs; nothing about a or b is fixed. Only the word "differentiable" adds the second equation a = 5. The mirror mistake is setting the slopes equal without matching the values: with a = 5 and b = 0 the pieces jump from 5 to 3 at x = 1, so the function is not continuous, let alone differentiable.

Quick check

Let f(x) = x^2 for x < 2 and f(x) = ax + b for x >= 2. Find a and b so that f is differentiable everywhere.

Answer

a = 4 and b = -4. Continuity at 2: the left value is 2^2 = 4, so 2a + b = 4. Differentiability at 2: the left derivative is 2x, which is 4 at x = 2, so a = 4. Then 2(4) + b = 4 gives b = -4. The pieces meet at (2, 4) with slope 4 on both sides.
