The Limit at a Point: Approach, Not Arrival

Objective. See why the limit at a point ignores the value there, why it exists only when the left-hand and right-hand limits agree, and how that one condition turns into continuity.
1.00x

Static explanation

For f(x) = (x^2 - 1)/(x - 1) the numerator factors as (x - 1)(x + 1), so away from x = 1 the function is exactly x + 1. At x = 1 it is undefined, because the denominator vanishes. The limit at 1 is nevertheless 2: as x approaches 1 from either side the values approach 2, and the value at 1 never enters the computation.

The numbers make it concrete. From the left: f(0.9) = 1.9, f(0.99) = 1.99, f(0.999) = 1.999. From the right: f(1.1) = 2.1, f(1.01) = 2.01, f(1.001) = 2.001. Both columns close in on 2, so the left-hand limit and the right-hand limit agree and the two-sided limit exists.

A limit can also fail. For g(x) = |x|/x the values are -1 for every negative x and +1 for every positive x, so the left-hand limit at 0 is -1 and the right-hand limit is +1. They disagree, so lim(x -> 0) g(x) does not exist. Nothing can repair a disagreement between the two sides.

Agreement is what continuity is built on. For h(x) = 2x + 1 when x < 3 and h(x) = 3x - 2 when x >= 3, both one-sided limits at 3 equal 7, and h(3) = 7 as well, so h is continuous at 3. Had the two sides disagreed, the function would jump and no value at 3 could fix it.

Common misconception

Computing a limit by substituting x = a and, when the result is 0/0, concluding that the limit does not exist. Substitution producing 0/0 says only that this particular evaluation is uninformative. In the first example substitution gives 0/0 and the limit is 2; in GATE CSE 2013 Q.22 one option has a perfectly good limit of 5 at x = 3 and is still discontinuous there, because f(3) = 4.

Quick check

Let f(x) = x + 2 for x < 1 and f(x) = 4 - x for x > 1, with f(1) = 0. Does the limit at 1 exist, and is f continuous at 1?

Answer

The limit exists and equals 3; the function is not continuous at 1. The left-hand limit is 1 + 2 = 3 and the right-hand limit is 4 - 1 = 3, so the two-sided limit is 3. But f(1) = 0 differs from 3, so the third condition for continuity fails and the break is a removable discontinuity.
