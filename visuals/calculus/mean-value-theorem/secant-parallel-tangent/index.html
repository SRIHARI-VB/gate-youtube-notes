The Secant and the Parallel Tangent

Objective. See where the mean value theorem point comes from: slide a tangent along the curve until it is parallel to the chord, and read the value of c. Then see Rolle's theorem as the flat-chord case, and see the guarantee disappear when the curve has a corner.
1.00x

Static explanation

Take f(x) = x cubed on [0, 2]. Its values at the ends are f(0) = 0 and f(2) = 8, so the chord joining (0, 0) to (2, 8) has slope (8 - 0)/(2 - 0) = 4. That number is the average rate of change of f over the interval.

The mean value theorem says that some interior point has an instantaneous rate of change equal to that average. Here f prime of x is 3x squared, so the tangent slope climbs from 0 at x = 0 to 12 at x = 2, and it must pass through 4 on the way. Setting 3c squared = 4 gives c = 2 over root 3, which is 1.1547, and it lies inside the interval. At that point f(c) = 1.5396 and the tangent has slope exactly 4, so the tangent is parallel to the chord.

Rolle's theorem is the same statement with a flat chord. For g(x) = x cubed minus 4x on [-2, 2] both endpoint values are 0, so the average slope is 0 and the theorem promises a horizontal tangent. Solving 3c squared - 4 = 0 gives c = 1.1547 and c = -1.1547, and both lie inside the interval: the theorem promises at least one point, not exactly one.

The hypotheses are not decoration. The modulus of x on [-1, 1] has equal endpoint values and a flat chord, but at 0 it has no derivative: the slope is -1 on the left and +1 on the right, and it never reaches 0. One point without a derivative is enough to destroy the guarantee.

Common misconception

Reporting the midpoint of the interval as the theorem's point. For x cubed on [0, 2] the midpoint is 1, where the derivative is 3, not 4. The midpoint is correct only for a quadratic, because there the equation for c is linear.

Quick check

For h(x) = x cubed minus 3x on [0, 2], find the point the theorem guarantees. Is it the midpoint?

Answer

c = 2 over root 3 = 1.1547, and it is not the midpoint. h(2) - h(0) = 2 - 0 = 2, so the average slope is 1. Setting 3c squared - 3 = 1 gives c squared = 4/3, and the positive root lies in (0, 2). At the midpoint x = 1 the derivative is 0, not 1.
