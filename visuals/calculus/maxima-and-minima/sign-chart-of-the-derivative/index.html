Where the Derivative Changes Sign

Objective. See why solving f'(x) = 0 only produces candidates, why the sign of f' on each side decides the verdict, and why a stationary point can fail to be an extremum.
1.00x

Static explanation

The curve is f(x) = 3x^4 - 16x^3 + 24x^2 + 37, the function from GATE CSE 2008 Q.25. Its derivative is f'(x) = 12x^3 - 48x^2 + 48x = 12x(x - 2)^2, which vanishes at x = 0 and at x = 2. Those two numbers are the only candidates for an extremum.

The candidates have to be classified, and the classification is the sign chart, not the list of zeros. For x below 0 the factor 12x is negative and (x - 2)^2 is positive, so f' is negative and f is falling. Between 0 and 2 both factors are positive, so f' is positive and f is rising. Above 2 both factors are again positive, so f' is positive and f keeps rising. Numerically f'(-0.5) = -37.5, f'(1) = 12 and f'(3) = 36.

At x = 0 the sign of f' goes from minus to plus, which is a local minimum, and f(0) = 37. At x = 2 the sign does not change at all: the curve flattens and then continues upwards, so f(2) = 53 is higher than f(0) but is not an extremum. This is the case the second-derivative test cannot settle, because f''(x) = 36x^2 - 96x + 48 gives f''(2) = 0. The first non-vanishing derivative there is f'''(2) = 48, of odd order, which confirms the verdict.

On the closed interval [-1, 4] there are two more candidates that no derivative can find: the endpoints. f(-1) = 80 and f(4) = 165, so the absolute maximum on that interval is 165 at x = 4, and the absolute minimum is 37 at x = 0.

Common misconception

Counting the solutions of f'(x) = 0 as the number of extrema. This function has two stationary points and exactly one extremum. A repeated root of f' - here (x - 2)^2 - is a place where the tangent is horizontal and the function does not turn.

Quick check

For the same function, how many extrema does it have on the whole real line, and of what kind?

Answer

One, a local minimum at x = 0. The sign of f' changes only at 0, from negative to positive, so f falls until 0 and rises afterwards. Since f grows without bound as x goes to either infinity, that single local minimum is also the global minimum, with value 37.
