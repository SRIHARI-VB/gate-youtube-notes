Two Directions a Matrix Cannot Turn

Objective. Sweep an input vector around the unit circle through A = [[2,1],[1,2]] and see that the matrix turns almost every vector, except at two directions where it only scales it. Those directions are the eigenvectors, the scale factors are the eigenvalues, and their sum and product are the trace and the determinant.
1.00x

Static explanation

A matrix is a rule that sends each vector to another vector. Usually both the direction and the length change, and there is nothing to say about the pair. An eigenvector is the exception: it is a nonzero vector x for which Ax stays on the same line through the origin, so Ax = lambda x for some scalar lambda, which is called the eigenvalue. The scalar may be larger than 1 (stretched), between 0 and 1 (shrunk), negative (flipped to the opposite ray) or 0 (collapsed onto the origin). Only the line is determined, never the vector, because every nonzero multiple of an eigenvector is again an eigenvector for the same eigenvalue.

For A = [[2,1],[1,2]] the picture gives the two directions directly: the unit vector along (1,1) is sent to (3,3), three times itself, and the unit vector along (1,-1) is sent to itself, so the eigenvalues are 3 and 1. The algebra agrees. The characteristic equation is det(A - lambda I) = lambda^2 - 4 lambda + 3 = 0, whose roots are 3 and 1, and the two coefficients are exactly the trace 4 and the determinant 3, so the eigenvalues of any 2 by 2 matrix always sum to the trace and multiply to the determinant.

This A is symmetric, and the two eigen-directions come out perpendicular. That is not a coincidence of the example: every real symmetric matrix has real eigenvalues, and eigenvectors belonging to different eigenvalues of a symmetric matrix are orthogonal. It is the reason a symmetric matrix can always be written Q Lambda Q^T with Q orthogonal, and the reason questions about symmetric matrices can be answered from the eigenvalues alone.

Common misconception

Reading "same line" as "same arrow". The eigenvector condition allows a negative eigenvalue, which sends the vector to the opposite ray while keeping the line, as [[0,1],[1,0]] does to (1,-1): the output is (-1,1), which is -1 times the input. The second mistake is treating the zero vector as an eigenvector, because A0 = 0 = lambda 0 for every lambda and every matrix, so allowing it would make every number an eigenvalue of every matrix.

Quick check

A = [[3,0],[0,3]]. Which vectors are eigenvectors, and how many distinct eigenvalues are there?

Answer

Every nonzero vector, and one eigenvalue, 3. A = 3I multiplies every vector by 3, so every line through the origin is kept. This is the extreme case behind GATE CSE 2026 Set 1 Q.3, where the maximum multiplicity of an eigenvalue of an n by n matrix is n.
