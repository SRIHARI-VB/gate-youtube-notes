Two Lines, Three Cases, and the Rank Test That Decides Which One

Objective. Read a 2 by 2 system as two lines, watch the three arrangements a pair of lines can be in, and see that the determinant alone separates only the first case from the other two. The rank pair decides the rest: rank(A) below rank([A|b]) is no solution, equality below n is infinitely many.
1.00x

Static explanation

A 2 by 2 system is two lines. The row picture asks where they meet: at one point (a unique solution), nowhere (parallel and distinct, no solution), or everywhere on a single line (the two equations describe the same line, infinitely many solutions). Those are the only three possibilities, because the solution set of a linear system is either empty or an affine copy of the null space of the coefficient matrix.

The determinant settles only the first of the three. If det(A) is not zero, the two rows are independent, the lines genuinely cross, and the system has exactly one solution for every right-hand side. If det(A) is zero, the rows are proportional and the lines are either parallel or identical, and the determinant cannot tell you which. What does tell you is the pair of ranks. rank(A) counts the independent rows of the coefficient matrix, rank([A|b]) counts the independent rows once the right-hand side is attached. Adding one column raises a rank by at most one, so the second number is either the first or one more than it: one more means the equations contradict each other and there is no solution; equal means they are consistent, and then rank(A) below the number of unknowns n leaves n - rank(A) free parameters, so the solution set is infinite.

The parameter cases are where this pays. For x + ky = 1 and kx + y = -1 the determinant is 1 - k2, which vanishes at k = 1 and k = -1. At k = 1 the equations are x + y = 1 and x + y = -1, parallel and distinct: no solution. At k = -1 they are x - y = 1 and -x + y = -1, the same line twice: infinitely many solutions. Same determinant, opposite answers, which is exactly why GATE CSE 2025 Set 1 Q.13 can offer both "exactly one value of k gives no solution" and "exactly one value of k gives infinitely many solutions" as true statements at once.

Common misconception

Stopping at "determinant zero, so infinitely many solutions". The determinant is computed from the coefficient matrix alone, while the number of solutions also depends on the right-hand side. The same singular matrix [[1,1],[2,2]] gives infinitely many solutions for b = (1,2), because x + y = 1 and 2x + 2y = 2 are the same line, and no solution for b = (1,3), because 2x + 2y = 3 contradicts 2x + 2y = 2. The second trap is the mirror image: concluding "no solution" from singularity alone. Both mistakes are caught by one comparison, rank(A) against rank([A|b]).

Quick check

A is 3 by 3 with det(A) = 0, and substituting b into the augmented matrix gives rank([A|b]) = 3. How many solutions has Ax = b, and which number on the answer sheet is that?

Answer

None. A zero determinant means rank(A) is at most 2, while rank([A|b]) is 3, so the ranks differ and the system is inconsistent. On a GATE answer sheet that is 0 solutions, not "infinite" and not "cannot be determined" - the augmented rank is what makes it certain.
