Bubbles and Flushes: Counting Cycles in a Five-Stage Pipeline

Objective. Draw the space-time diagram for the four situations GATE asks about and read the answer off the columns. Four instructions with nothing in their way take 8 columns. A RAW pair on an ALU result costs 2 bubbles without forwarding and 0 with it. A load followed immediately by a use costs exactly 1 bubble that no wire can remove. A taken branch throws away 2 fetched instructions, so a six-instruction program finishes in cycle 10 instead of 8. Every one of those numbers is the same arithmetic as the CPI model.
1.00x

Static explanation

In a five-stage pipeline an instruction passes through IF, OF, EX, MA and RW, one stage per clock cycle. Draw each instruction as a row and each cycle as a column: the row is shifted one column right of the row above it, and the number of columns is the time the program takes. With n instructions and no hazards that is k + n - 1 columns, so four instructions need 5 + 4 - 1 = 8 cycles. The first instruction finishes at the end of cycle 5 and one more finishes every cycle after that.

A data hazard is an arrow that points backwards in time. ADD R1, R2, R3 writes R1 at the end of its RW stage, cycle 5. SUB R4, R1, R5 reads R1 in its OF stage, cycle 3. Two cycles are missing, so something must give. Without forwarding the interlock inserts two bubbles and the program grows to 10 columns. With forwarding the ALU result is taken from the EX/MEM register at the end of cycle 3 and fed into the SUB's EX input in the same cycle, so the two bubbles vanish and the program stays at 8 columns.

One pair cannot be fixed that way. LOAD R1, [A] produces its word at the end of the MA stage, cycle 4, while the ADD behind it would need the word at the start of its own EX stage in cycle 4. The value does not exist when it is wanted, so exactly one bubble is inserted, the ADD executes in cycle 5, and the pair takes 7 columns. That single stall is why the statement "forwarding cannot prevent all pipeline stalls" is true, and it is the number GATE CSE 2024 Set 1 Q.30 asks about.

Control hazards cost whole instructions rather than single cycles. If I3 is a branch to I6 and the branch resolves in the EX stage, the fetch unit has already brought in I4 and I5. Both are wrong and both are cancelled, I6 is fetched in cycle 6, and the program ends in cycle 10. The penalty is 2 cycles here; in a modern 15- or 20-stage machine the same reasoning gives more than 20, which is why branch prediction exists.

Common misconception

The frequent error is to treat a bubble as a lost instruction. It is not: a bubble has its control signals cleared, so it writes no register and touches no memory, and the instruction behind it executes correctly one cycle later. The second error is to believe forwarding removes every data stall. It removes the ALU-to-ALU ones; the load-use pair keeps its single cycle, because the word leaves memory too late to be forwarded into the same cycle in which it is needed.

Quick check

Two instructions follow a LOAD and both read the loaded register: LOAD R1, [A]; ADD R2, R1, R3; SUB R4, R1, R5. With full forwarding, how many bubbles does the three-instruction block need, and how many columns does it take?

Answer

One bubble, and 8 columns. Only the first consumer is too close: the ADD would need R1 at the start of its EX stage in cycle 4 while the load produces it at the end of cycle 4, so one bubble is inserted and the ADD executes in cycle 5. The SUB is served by the ADD's EX/MEM result with no stall of its own. The block is 5 + 3 - 1 + 1 = 8 columns.
