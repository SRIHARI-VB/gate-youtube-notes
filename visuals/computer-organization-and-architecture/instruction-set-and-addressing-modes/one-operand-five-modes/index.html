One Address Field, Six Readings: Effective Address and Memory Cycles

Objective. Read the same address field under six addressing modes and see the effective address, the operand and the number of operand memory references change while the instruction stays put. The field holds 500, M[500] holds 1200, M[1200] holds 42, R2 holds 1200, R3 holds 700 and the PC holds 700.
1.00x

Static explanation

An instruction carries an opcode and an operand field. The field is just bits: the addressing mode is the rule that says what those bits mean, and the effective address is what that rule computes. Here the field is 500 and it never changes; what changes is the rule.

Immediate mode treats the field as the value, so the operand is 500 and no memory is read. Direct mode treats the field as the address, so the effective address is 500 and one read returns M[500] = 1200. Indirect mode treats the field as the address of an address: one read gives 1200, a second read gives M[1200] = 42. Register indirect does the same with a pointer already in a register, so R2 = 1200 is the effective address and one read gives 42. Indexed mode adds a register to the field, 500 + 700 = 1200, and one read gives 42. PC-relative mode adds the program counter, 700 + 500 = 1200, and one read gives 42.

So four of the six readings reach the same operand, 42, by different routes, and the routes differ in cost: zero reads for immediate, one for direct, register indirect, indexed and PC-relative, and two for indirect. The address arithmetic - adding a register or the PC - costs no memory traffic at all; only the reads cost. This is exactly the count GATE asks for when it asks how many memory cycles an instruction needs during its execution cycle.

Common misconception

Two mistakes dominate. The first is expecting a direct operand to be 42: direct mode stops one level up, so its operand is 1200, the value stored at 500, and reaching 42 needs indirection. The second is counting the extra words of a multi-word instruction as execution cycles - those words arrive during the instruction fetch, which is why GATE CSE 2005 Q.65 answers 4 and not 6.

Quick check

The same field of 500 is read in indexed mode, but R3 is changed to 800. What is the operand, and how many reads does it take?

Answer

Unknown from this picture, and one read. The effective address becomes 500 + 800 = 1300, which is a location this memory picture does not describe. The read count does not depend on the value of the index, only on the mode: indexed addressing always needs exactly one operand read.
