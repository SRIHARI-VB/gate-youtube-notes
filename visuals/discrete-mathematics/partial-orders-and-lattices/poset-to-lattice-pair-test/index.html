From Poset to Lattice: One Pair at a Time

Objective. Decide whether a five-element poset is a lattice by sweeping its pairs, see why only the incomparable pairs can fail, and see how deleting one covering pair breaks the lattice property and how adding it back repairs it.
1.00x

Static explanation

The poset is the one from GATE CSE 2017 Set 2 Q.21: X = {a, b, c, d, e} with a below every element, e above every element, b below c, and a below d below e. Its Hasse diagram has five covering pairs - a-b, a-d, b-c, c-e, d-e - and the relation itself has thirteen pairs, because transitivity supplies a-c, b-e and a-e as well as the five reflexive pairs.

A poset is a lattice when every pair of elements has a least upper bound and a greatest lower bound inside the poset. Comparable pairs are free: if b < c then the join of b and c is c and the meet is b. Only the incomparable pairs need work, and here there are just two, {b, d} and {c, d}.

For {b, d} the elements above both are e alone, so the join is e; the elements below both are a alone, so the meet is a. For {c, d} the same two elements answer: join e, meet a. Every pair is settled, so the poset is already a lattice and the minimum number of ordered pairs that must be added is 0.

The last step deletes the covering pair d < e. Now d is maximal, nothing lies above both b and d, and the pair has no join: one missing bound is enough to refute the lattice property, and adding that single pair back restores it. That is the shape of the question when the answer is not zero.

Common misconception

Judging lattice-hood from the picture - "it has a single top vertex, so it must be a lattice". A single top vertex does not help: the failure is always a pair with two incomparable upper bounds, or no upper bound at all. In the broken variant the top vertex e is still there, and the poset is still not a lattice, because e is not above d. The reliable test is the pair sweep, and the fast version checks only the incomparable pairs.

Quick check

In the broken variant (the covering pair d < e deleted), which pairs lose a bound, and how many ordered pairs must be added to make it a lattice again?

Answer

The pairs {b, d} and {c, d} lose their join, and adding the single pair (d, e) repairs both. With d < e restored, d is below e, so e is above b and d and above c and d, and the joins return. Adding the single pair (d, e) restores both joins, and the relation grows by exactly one pair - the pairs (b, e) and (a, e) never left, because the chain a < b < c < e still carries them.
