Quantifier Order: for all x there exists y versus there exists y for all x

Objective. See on one table why for all x there exists y and there exists y for all x are different claims, and why only one of them implies the other.
1.00x

Static explanation

A two-place relation R on a domain is a table: rows are the first argument x, columns are the second argument y, and a tick at row x, column y means R(x, y) is true.

For all x there exists y R(x, y) says every row has at least one tick. The y is chosen after x is known, so different rows may use different columns. There exists y for all x R(x, y) says some column is completely full: one fixed y that works for every x.

On the domain {1, 2, 3} with R = {(1,2), (2,3), (3,1)} every row has exactly one tick, so the first claim is true, while no column has three ticks, so the second is false. That single table is the standard counterexample.

The implication runs one way only. If a full column exists then every row has a tick in it, so there exists y for all x R(x, y) implies for all x there exists y R(x, y). The reverse fails, as the table shows. Quantifiers of the same kind do commute: for all x for all y is the same as for all y for all x, and likewise for two existentials.

Common misconception

Reading for all x there exists y as though one y had to serve every x. The order decides whether y may depend on x; swapping a universal and an existential changes the claim. GATE CS 2023 Q.16 rewards the correct direction: a single y that works for all x is the stronger statement.

Quick check

On the domain {1, 2} with R = {(1,2), (2,1)}, which of the two claims hold?

Answer

For all x there exists y R(x, y) holds; there exists y for all x R(x, y) does not. Row 1 ticks column 2 and row 2 ticks column 1, so both rows have a tick. Column 1 is missing row 1 and column 2 is missing row 2, so no column is full.
