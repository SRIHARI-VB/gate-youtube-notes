# Truth tables: implication and its converse

p5.js lesson. Four steps: the four interpretations, the single false row of p -> q, the identical column of not p or q, and the two rows where the converse differs.

Verified facts (recomputed in `scripts/validate.py`): 2^2 = 4 rows; p -> q is false only at (T, F); p -> q and not p or q agree in all four rows; q -> p differs from p -> q in exactly two rows.

Source: playlist Part 1 (JnsT3ezRzuo) and Part 2 (SRiIR-taO5k); PYQs GATE CS 2021 Set 1 Q.7 and GATE CS 1992 Q.2(xvi).
