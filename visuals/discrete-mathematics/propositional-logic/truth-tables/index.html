Truth Tables: Implication and Its Converse

Objective. See why p -> q is false in exactly one row, why not p or q is the same column, and why the converse is not.
1.00x

Static explanation

A truth table lists every interpretation of a formula. With n variables there are 2n rows, so two variables give 4 rows and three give 8. Each row is one interpretation: one complete assignment of true and false to the variables.

The implication p -> q is false in exactly one row, where p is true and q is false. Everywhere else it is true, including both rows where p is false - that is vacuous truth, and it is the part beginners find strangest. Because only one row can break it, checking an implication usually means checking one row.

not p or q has the same four values as p -> q. Two formulas are logically equivalent exactly when their columns match in every row, so this single table proves the implication law.

The converse q -> p is a different column. It disagrees with the original in the two rows where p and q differ, which is why the converse of a true statement can be false: a wet ground does not have to mean rain.

Common misconception

“p implies q” is often read as “p and q rise and fall together”, which is the biconditional. Implication allows q to be true while p is false. At p = false, q = true the formula p -> q is true, and so is q -> p; they disagree only when exactly one of them is false.

Quick check

In which single row is p -> q false?

Answer

p = true, q = false. That is the only row where an implication fails, which is why a falsifying assignment is the fastest disproof of any implication-shaped claim.
