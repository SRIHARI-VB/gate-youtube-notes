# Converse, inverse and contrapositive

p5.js lesson. Four steps: the statement p -> q, the contrapositive column, the converse column, and the inverse column.

Verified facts (recomputed in `scripts/validate.py`): p -> q and not q -> not p agree in all four rows; q -> p and not p -> not q each differ from p -> q in exactly two rows.
