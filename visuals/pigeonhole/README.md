# Pigeonhole: Guarantees, not Odds

Objective: Turn a probabilistic-sounding question into a certain one by constructing the worst case.

Controls: play/pause, previous/next step, restart, speed. Keyboard: left/right arrows step, space plays.
A static explanation, a misconception and a quick check sit outside the canvas, so the lesson is usable with animation off or reduced motion.

The page loads p5.js from a CDN, so the first open needs an internet connection; if the CDN is unreachable the page says so and the static lesson still works.

Source: Topic: pigeonhole principle. Playlist video: Part 10 (xocsjqBkQaE). Verified PYQ: GATE CS 2000 (minimum cards, answer 9).
