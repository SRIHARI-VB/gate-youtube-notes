From a 4-to-1 Multiplexer to a Minimal Sum of Products

Objective. Take one four-to-one multiplexer - select lines S1 = P and S0 = Q, data inputs 0, 1, R and R' - and follow it all the way: read the select codes, substitute the data inputs, expand to the four minterms 2, 3, 5 and 6, place them on a three-variable map, group them, and read off the minimal sum of products. The order of the steps is the lesson.
1.00x

Static explanation

A four-to-one multiplexer has two select lines, so it has 2^2 = 4 data inputs and one output. The output is the sum of four products, one per select code, each product being the select code's minterm multiplied by the data input that the code owns: Y = S1'S0'I0 + S1'S0I1 + S1S0'I2 + S1S0I3. Because exactly one select code is true at any moment, only one term can be non-zero, and the circuit is simply a switch.

This question fixes S1 = P and S0 = Q and gives the data inputs 0, 1, R and R'. Substituting: the code 00 multiplies I0 = 0, so that term vanishes; 01 gives P'Q; 10 gives PQ'R; 11 gives PQR'. Expanding P'Q over the third variable gives minterms 2 and 3, so the function is 1 at exactly the four rows 2, 3, 5 and 6 of the eight-row truth table.

On a three-variable map with rows P and columns Q R in Gray order, minterm 3 is the third cell of the top row and minterm 2 is the fourth. Minterms 2 and 3 are neighbours and give P'Q; minterms 2 and 6 are neighbours vertically and give QR'; minterm 5 has no neighbour left and stays as PQ'R. The minimal sum of products is therefore P'Q + QR' + PQ'R, three terms and seven literals, against four terms and twelve literals for the canonical form. That is option (A) of the paper.

Common misconception

Three mistakes dominate this question. Numbering the map cells by position instead of by their Gray-code labels, which puts minterm 2 and minterm 3 the wrong way round and turns P'Q into a group that does not exist. Grouping only along the drawn edges and missing the vertical pair 2 and 6, which loses QR' and leaves a larger answer. And reading the select codes in the wrong order, taking Q as the more significant select bit - then the data inputs line up with a different set of minterms and every term is wrong.

Quick check

Which group on the map produces the term QR', which minterms does it cover, and how many literals does it save compared with writing those minterms out?

Answer

Minterms 2 and 6, the last column of both rows. In those two cells Q = 1 and R = 0 while P takes both values, so the term keeps Q and R' only. The two canonical minterms P'QR' and PQR' carry three literals each - six in all - and the group carries two, so the pair saves four literals.
