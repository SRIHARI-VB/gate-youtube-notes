IEEE 754 Bit Fields to Value

Objective. Decode one single-precision word - 0xC2710000 - in the order that works: expand the hex to bits, cut 1 / 8 / 23, read the sign, unbias the exponent, restore the hidden 1, then move the point. Then see why the largest finite number cannot use an all-ones exponent.
1.00x

Static explanation

Single precision is thirty-two bits: one sign bit, eight exponent bits and twenty-three fraction bits, always cut from the left. The word 0xC2710000 expands digit by digit to 1100 0010 0111 0001 0000 0000 0000 0000, so the sign bit is 1 and the number is negative, the exponent field is 10000100 = 132, and the fraction field begins 1110001.

The exponent field is stored with a bias of 127 added, so the exponent used in the value is 132 - 127 = 5. The fraction field holds only what comes after the binary point of the significand; in normal form there is a 1 in front of the point that is never stored, so the significand is 1.1110001. Adding the place values gives 1 + 0.5 + 0.25 + 0.125 + 0.0078125 = 1.8828125.

The value is that significand times two to the true exponent: 1.8828125 x 32 = 60.25. Equivalently, move the binary point five places right and read 111100.01, which is 32 + 16 + 8 + 4 + 0.25. Applying the sign bit gives -60.25, and the answer is exact at two decimal places.

The last step is about the two reserved exponent fields. All zeros means zero (with a zero fraction) or a subnormal (with a non-zero fraction, and no hidden 1). All ones means infinity (zero fraction) or NaN (non-zero fraction). So the largest finite single-precision number has exponent field 1111 1110, which is 254, and a full fraction: about 3.40 x 10^38.

Common misconception

Two mistakes dominate. Dropping the hidden 1 gives 0.8828125 x 32 = 28.25, and forgetting the bias gives 1.8828125 x 2^132. A third: reading the eight hex digits as a decimal magnitude, which is not a decode at all. And on the largest-number question, choosing the word whose exponent field is all ones - that word is NaN or infinity, not the largest finite number, because the field 255 is reserved.

Quick check

Decode 0x3F800000, and say what exponent field the largest finite positive number has.

Answer

0x3F800000 is 1.0. The sign is 0, the exponent field is 0111 1111 = 127 so the true exponent is 0, and the fraction is all zeros so the significand is 1.0. The largest finite positive number has exponent field 1111 1110 = 254 with a full fraction; an all-ones exponent is infinity or NaN.
