From a Shift Register to the Johnson Cycle

Objective. Take four D flip-flops in a chain and feed the complement of the last output back to the first input. Follow the register through all eight states from 0000, watch the block of ones grow and then shrink, see why the count is 2n rather than n, and see where the other eight patterns of a four-bit register go. The circuit is the one two verified GATE questions are about.
1.00x

Static explanation

A shift register is a chain of D flip-flops sharing a clock: each stage copies its left neighbour on every clock edge, so a bit entering at one end travels one stage per clock. A ring counter closes the loop by wiring the last output straight back to the first input, and then a single 1 walks round the register, giving exactly n states for n stages. A Johnson counter, also called a twisted-ring or switch-tail counter, closes the loop through an inverter instead: the first stage takes the complement of the last stage's output.

That one inverter doubles the cycle. Starting from 0000 the last bit is 0, so its complement 1 shifts in, giving 1000; the ones keep arriving while the last bit is still 0, giving 1100, 1110 and then 1111. At that point the last bit is 1, so the inserted bit becomes 0 and the block of ones shrinks from the left: 0111, 0011, 0001, and the eighth clock restores 0000. Eight states, which is 2n for n = 4. Read as decimal with the leftmost bit as the most significant, the cycle is 0, 8, 12, 14, 15, 7, 3, 1 and back to 0, and consecutive states differ in exactly one bit, so the sequence is a Gray code.

Four flip-flops hold sixteen patterns, so eight are left over, and they are not dead states: they form a second cycle of length eight. Starting at 0010 gives 0010, 1001, 0100, 1010, 1101, 0110, 1011, 0101 and back, again eight states. A Johnson counter is therefore not self-starting, because where it lands depends on where it began, and a reset that loads a known state is what makes it deterministic. The unused count is 2^n - 2n, which is 16 - 8 = 8 here.

Common misconception

Three mistakes dominate this circuit. Reporting n states instead of 2n, which is the ring counter's answer and the single most common slip. Forgetting that the feedback is inverted, which turns the sequence into a ring rotation and gives four states instead of eight. And reading the four-bit patterns as if the newest bit were the least significant, which reverses the decimal order and turns 0, 8, 12, 14, 15, 7, 3, 1 into 0, 1, 3, 7, 15, 14, 12, 8 - the first option offered in GATE CSE 2015 Set 1 Q.20 and the wrong one.

Quick check

How many flip-flops does a Johnson counter need to divide by ten, how many patterns would a register of that width leave unused, and what does a ring counter of the same modulus need instead?

Answer

Five flip-flops, 22 unused patterns, and ten flip-flops for the ring version. A Johnson counter of n stages has 2n states, so 2n = 10 needs n = 5, and five flip-flops hold 32 patterns of which 10 are used, leaving 22. A ring counter has n states, so the same modulus needs ten stages - twice the flip-flops, in exchange for needing no inverter and for having no second cycle.
