Preorder, Inorder, Postorder: Three Walks of One Shape

Objective. One tree, seven nodes, three orders. Watch the same shape produce 4 2 1 3 6 5 7, then 1 2 3 4 5 6 7, then 1 3 2 5 7 6 4, and see that the only thing that changes is where the root is printed. The tree is a binary search tree, which is why its inorder comes out sorted - the fact GATE CSE 2020 Q.5 and GATE CSE 2017 Set 2 Q.36 rely on when they hand you a preorder and ask for the postorder.
1.00x

Static explanation

All three depth-first orders run the same recursion over the same tree. At each node they do three things in a different order: visit the node (N), walk the left subtree (L), walk the right subtree (R). Preorder is N L R, inorder is L N R, postorder is L R N.

Because every node is visited exactly once, each order costs Theta(n) time: seven nodes, seven visits. The recursion holds one frame per level, so the auxiliary space is the height plus one, which is 3 frames here for a tree of height 2. That does not change with the order.

Read the sequences as a single sentence about the root. Preorder prints a node before anything under it, which is why it is the order a copy or a serialisation uses. Postorder prints a node after everything under it, which is why it is the order that frees a tree or evaluates an expression tree. Inorder prints a node between its two subtrees, and on a binary search tree that places every key after all smaller keys and before all larger ones, so the sequence is sorted.

The last steps change the shape and keep the rules. On a chain 1 - 2 - 3 leaning right, the preorder and the inorder are both 1 2 3 while the postorder is 3 2 1. Two different shapes sharing a sequence is exactly why a single traversal never determines a tree, and why GATE CSE 2004 Q.35 rules out preorder with postorder as a unique pair.

Common misconception

That the order depends on the values in the nodes. It does not: it depends on the shape. Two trees with the same shape give the same three sequences whatever keys they hold. The sorted inorder is a consequence of the search-tree rule, not of the traversal.

Quick check

The same three orders are taken on a right-leaning chain 1 - 2 - 3. What are the sequences?

Answer

Preorder 1 2 3, inorder 1 2 3, postorder 3 2 1. On a chain with no left child anywhere, L is empty at every node, so N L R and L N R collapse to the same sequence. That collapse is the reason preorder and inorder are not interchangeable evidence about a shape.
