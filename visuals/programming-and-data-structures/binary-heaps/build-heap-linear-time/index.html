Build-Heap Bottom Up Is Linear

Objective. Ten keys, five heapify calls, seven swaps, and the array becomes a max-heap. Watch the loop start at the last internal node and walk backwards to the root, and see why the work shrinks as the loop climbs: the nodes that could sink far are few, and the nodes that are many sink almost nowhere.
1.00x

Static explanation

Build-heap takes an array that is a complete tree in shape but not a heap in order, and runs heapify on every internal node from index floor(n/2) down to 1. Leaves are skipped because a one-node subtree is already a heap. The order of the loop matters: when heapify(i) runs, both subtrees of i are already heaps, which is the precondition a sink needs.

The cost is not n times log n. A node at height h sinks at most h steps, and a complete tree has about n/2^(h+1) nodes at height h, so the total is the sum of h*n/2^(h+1) over h. That sum is below 2n and approaches n, so the build is Theta(n). Half of the nodes are leaves and cost nothing, a quarter cost at most one step, and only the root can cost the full height.

This is the fact behind two previous-year questions. GATE CSE 2008 Q.47 asks for the cost of adding n keys to a heap of n and the answer is Theta(n), because the keys may be appended and one build run over the 2n cells. The third statement of GATE CSE 2019 Q.40 says a max-heap can be built from a binary search tree in Theta(n), which is the same linear build after a linear walk.

Common misconception

That build-heap is O(n log n) because heapify is O(log n) and there are about n/2 calls. That multiplies a worst case by a count that never attains it. For n = 1023 the exact sum is 1017.006 steps, below 2n = 2046 and far below n log n = 10230.

Quick check

Build a max-heap from [1,2,3,4,5]. How many swaps does it take, and what is the array?

Answer

[5,4,3,1,2] after three swaps in two heapify calls. n = 5, so the calls run at i = 2 then i = 1. At i = 2 the key 2 has children 4 and 5, so it swaps with 5: [1,5,3,4,2]. At i = 1 the key 1 swaps with 5: [5,1,3,4,2], then at index 2 it swaps with 4: [5,4,3,1,2].
